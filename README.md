### About

I design and build infrastructure, monitoring, and backend systems — from containerized deployments and IP/network management to real-time video pipelines and computer-vision services. Security isn't bolted on afterward: segmentation, least-privilege access, and hardening are part of how each project is architected from the start. The projects below are things I've built end-to-end: architecture, deployment, and the operational tooling around them.

### Featured Projects

#### 🎥 [stream-quality-monitor](https://github.com/Maximum-Infra/stream-quality-monitor)
Fleet monitor for Janus WebRTC video streams — detects black frames, blur, freeze, and stalls via headless-browser sampling, exposes Prometheus metrics so anomalies get caught early, not just quality ones.

#### 🧠 [facerec](https://github.com/Maximum-Infra/facerec)
Local face-recognition lab app (OpenCV YuNet + SFace) with calibration, anti-spoof / liveness detection to resist presentation attacks, data-retention policies, and event webhooks — full Docker Compose stack with a FastAPI backend and React frontend.

#### 🌐 [ipam-dashboard](https://github.com/Maximum-Infra/ipam-dashboard)
Design and NetBox deployment write-up for an internal IP/subnet management dashboard — site/VLAN/prefix modeling for network segmentation, bulk import tooling, and a dashboard concept for network visibility.
